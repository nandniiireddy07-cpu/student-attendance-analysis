# Analysis of Student Attendance vs Academic Performance

## Project Overview
This project analyzes the relationship between student attendance and academic performance using Python and data analytics techniques.

The project explores whether attendance levels are associated with differences in students' final examination marks.

## Objectives
- Analyze student attendance and academic performance.
- Clean and prepare the dataset.
- Perform Exploratory Data Analysis (EDA).
- Study the correlation between attendance and final marks.
- Compare performance across attendance groups.
- Visualize findings using charts and statistical summaries.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib  
- Seaborn
- SciPy
- Google Colab
- GitHub

## Dataset
The project report describes a dataset containing 500 student records and 9 columns. The variables include Attendance, InternalMarks, FinalMarks, StudyHours, AssignmentScore, PreviousSemesterScore, and Attendance_Group.

## Methodology
1. Load the dataset using Pandas.
2. Check missing values and duplicate records.
3. Calculate descriptive statistics.
4. Perform Exploratory Data Analysis.
5. Create visualizations to identify patterns.
6. Analyze correlations and compare attendance groups.
7. Interpret the results and document limitations.

## Key Findings
- Mean attendance: 77.90%.
- Mean final marks: 71.46.
- Pearson correlation between attendance and final marks: 0.324.
- Mean final marks across attendance groups:
  - Low: 66.38
  - Medium: 71.06
  - High: 76.96

These findings indicate a positive association between attendance and final marks in the analyzed dataset. Correlation does not establish causation.

## Limitations
The analysis is based on the selected dataset. The findings do not prove that attendance alone causes changes in academic performance.
